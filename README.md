# Personal Budgeting App

**An offline-first mobile budgeting app for tracking income and expenses**

Generated by Bob-BusinessConsultant

## Overview

This is a personal budgeting application designed to help individuals track their income and expenses, set budget limits, and gain insights into their spending patterns. The app prioritizes offline functionality, allowing you to log expenses anytime, anywhere, with automatic cloud sync when connectivity is restored.

## Key Features

- ✅ **Offline-First**: Full functionality without internet connection
- 💾 **Cloud Backup**: Automatic sync to cloud when online
- 📊 **Budget Tracking**: Set limits and get visual warnings
- 📈 **Reports & Analytics**: Visualize spending patterns with charts
- 🔒 **Secure**: Encrypted data at rest and in transit
- 📱 **Cross-Platform**: iOS and Android from single codebase
- 💰 **Zero Cost**: Completely free and open source

## Technology Stack

- **Mobile Framework**: React Native
- **Local Database**: WatermelonDB (SQLite)
- **Cloud Backend**: Supabase (PostgreSQL + Auth + Realtime)
- **UI Components**: React Native Paper
- **Charts**: Victory Native
- **State Management**: Zustand

## Getting Started

### Prerequisites

- Node.js 18+ (LTS)
- React Native CLI or Expo CLI
- Android Studio (for Android) or Xcode (for iOS)
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Da-code135/personal-budgeting-app.git
cd personal-budgeting-app

# Install dependencies
npm install

# Start development server
npm start
```
